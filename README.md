# WhiteSur GTK Theme 🚀

Este repositório contém a minha versão personalizada do popular tema **WhiteSur GTK**, projetado para deixar a interface do Linux com a identidade visual inspirada no macOS. 

O projeto original foi desenvolvido por [Vince Liuice](https://github.com). Os créditos e a licença originais estão preservados nas pastas deste repositório.

---

## 💻 Compatibilidade
* **Interface Gráfica:** GNOME
* **Hospedagem:** Uso pessoal e backup público

---

## 📥 Como Instalar no GNOME

Siga o passo a passo abaixo pelo terminal para instalar o tema na sua pasta de usuário:

### 1. Criar a pasta de temas (caso não exista)
```bash
mkdir -p ~/.themes
```

### 2. Clonar este repositório
Baixe os arquivos diretamente para a pasta de temas do seu sistema:
```bash
git clone https://github.com ~/.themes/WhiteSur-Custom
```

---

## 🛠️ Como Aplicar o Tema

Para ativar o visual das janelas no GNOME, você precisará da ferramenta **GNOME Tweaks** (Ajustes).

1. Se ainda não tiver o aplicativo instalado, abra o terminal e digite:
   ```bash
   sudo apt install gnome-tweaks gnome-shell-extensions -y
   ```
   *(Comando válido para distribuições baseadas em Ubuntu/Debian. Se usar Fedora, utilize `sudo dnf install gnome-tweaks`).*

2. Abra o menu de aplicativos do seu Linux e procure por **Ajustes** (ou *Tweaks*).
3. Na barra lateral esquerda do aplicativo, clique na aba **Aparência** (Appearance).
4. No campo **Legado de Aplicativos** (Legacy Applications) ou **Janelas** (Windows), clique no menu do lado direito e selecione **WhiteSur-Custom**.
5. O visual das janelas mudará instantaneamente!
